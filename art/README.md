# Art

All of the game's art is generated by **Codex** with OpenAI image generation and placed straight into `public/assets/`, where the game loads it through `public/assets/manifest.json`.

| File | What it is |
|---|---|
| [`STYLE.md`](STYLE.md) | The look: the master style prompt, add-on blocks, rules, the cast's palettes, and approved anchors |
| [`PRODUCTION.md`](PRODUCTION.md) | Codex's instructions: file layout, sprite-sheet layouts, processing, the manifest format, QA |
| [`waves/`](waves/) | The asset lists with prompts, one file per wave |
| `review/` | Galleries Codex builds after each pass. Open them on github.com to see the art. |

## How to run a wave with Codex

1. **Before wave 00:** if you liked your ChatGPT test image, put it in the repo as `art/incoming/key_art.png` (and the battle one as `art/incoming/battle_mock.png`). Codex will use them as the anchors instead of generating new ones.
2. Tell Codex:

   > Produce the art in `art/waves/wave-00-anchors.md`, following `art/PRODUCTION.md` exactly. Stop at the gate.

3. Open `art/review/wave-00.md` on github.com, look it over with him, and tell Codex what's approved or what to change.
4. Before wave 01, **fill in the Hero Forge block** at the top of `art/waves/wave-01-first-battle.md` with him. Then do the same for wave 01. It has two gates: character designs first, then everything else.
5. Tell Claude when a wave is approved. Claude wires the art into the game.

**He's the art director.** Show him each review gallery and write down what he says. Changes go back to Codex in his words.
