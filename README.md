# Crystal Titans (working title)

A Final Fantasy–style RPG for a Utah 3rd grader where every attack is a piece of 3rd grade. Knight strikes are subtraction, Gunner volleys are multiplication, spells are cast by spelling, and Titans are summoned by writing. He picks how hard each move is, and harder hits harder.

**Status:** design phase. Nothing playable yet.
