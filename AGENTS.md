# Agent notes

**Crystal Titans** is a learning RPG for a Utah 3rd grader. Read `README.md` and `docs/` for the design.

- **Art tasks:** follow `art/PRODUCTION.md` exactly. It says which paths you may change, how to name and process files, and where to stop for approval.
- Don't edit `docs/`, `art/STYLE.md` or game code unless the task asks you to.
- Everything is for an 8-year-old: kid-safe content, and never use franchise names or lookalikes (Final Fantasy, Monkey Island, Pokémon, Godzilla, Star Wars) in prompts, art or text.
